## 1. 결정은 두 층이다

### 층 1: 엔진(에이전트 구조) — 1단계에서 세 명이 독립적으로 같은 결론

AI 엔지니어(14번 결론 1~2), 컴플라이언스 책임자(16번 결론 2, 아이디어 2 "공개 쌍둥이 리허설"), 사용자 리서처(11번 아이디어 1 "방문 설계도")가 따로 같은 구조에 도달했다.
- 외부 LLM은 질문과 공개 명세(컬럼명·코드표), 허브 공개 데이터만 보고 분석 계획(JSON)과 도구 호출을 맡는다.
- 명세대로 만든 가상 데이터(또는 구조가 비슷한 허브 공개 데이터)로 계획을 먼저 실행해 보고, 오류를 LLM에 돌려줘 고친다(계획, 실행, 검증, 재시도 고리).
- 센터 CSV는 센터 PC 안의 로컬 코드(DuckDB/pandas)만 계산한다. 숫자는 LLM을 거치지 않고 코드가 표·차트·문장 빈칸에 채운다(숫자 환각 차단).
- 외부 전송 경계는 프롬프트가 아니라 코드와 자동 테스트로 강제하고, 외부 전송 0건을 시연으로 보여 줄 수 있다.
- 로컬 소형 LLM은 핵심 경로에서 뺀다(GTX 1060 3GB, 드라이버 570 이상 필요, 2B 안팎 모델만 가능, 실측 불가. 14번 3절).
- 반대로 "10 미만을 가린 집계표를 외부 LLM에 보내 해석받는 구조"는 다른 팀이 몰린 방향이고 센터 탑재 위험이 높다(14번 결론 5, 16번 결론 1).

평가자는 이 엔진을 기본 전제로 두되, 후보마다 이 엔진이 잘 맞는지, 다른 구조가 더 나은지 판단해도 된다.

## 3. 1단계에서 나온, 모든 후보에 걸리는 사실

- 센터 2026년 4월 "데이터 프리존" 전환으로 도민·소상공인도 연구계획서 없이 데이터 65종 이용 가능, 그러나 실제 방문자는 아직 대부분 기관·기업(11번).
- 사용자가 가장 심하게 막히는 곳: 어떤 데이터를 어떤 조건으로 받을지 모름, 반출 심사 반려. 다음: 1개월 단위 파일 합치기, 영문 컬럼·코드 해독, SQL·통계 지식 부족(11번).
- 2026년 현안: 내국인 관광 감소(10월 1~25일 전년 대비 12.7% 감소), 원도심 공실 17.8%, 탐나는전 적립률 20% 뒤 캐시백 일시 중단과 발행 규모 급증. 주최 측 AI 정책 대상 산업은 에너지·청정바이오·우주항공이라 관광·지역화폐를 반길 것이라는 판단은 추론(12번).
- 센터 데이터 70종 중 21종(버스·교통량·와이파이·날씨·폐기물)은 원본까지 반출 가능. 지금도 쌓이는 센터 데이터: 카드 v02(2023-08~ 월), 외식업 포스(2018-11~), 유동인구 v02(2025-04~05~ 일), 종량제봉투(2012~ 일). 내·중국인 카드 6종과 기업 8종은 오래됨(13번).
- 결합 함정: 카드·포스는 법정동 73개, 유동인구·종량제봉투는 행정동 43개라 바로 못 잇는다. 공통 키는 7개 권역과 연월뿐. 정류소 ID와 날짜는 허브·센터가 깔끔히 맞는 드문 키(13번).
- 허브 Open API 형식: GET https://open.jejudatahub.net/api/proxy/{데이터ID}/{프로젝트키}?startDate=YYYYMMDD&endDate=YYYYMMDD, 확인한 1건의 일일 쿼터 1000. 키는 로그인 후 마이페이지에서 프로젝트 생성. "자동갱신" 데이터가 실제로 2026년 값을 주는지는 미확인(13번).
- 반출 정책 원문 추가 조항: 응용집계(비율·증감률·순위·지수)는 수치 포함 반출 가능, 시각화는 png·jpg만, 소스코드에 데이터 출력이 남으면 반출 불가, 10 미만 처리는 범주·삭제·비식별 3가지, 원본 제공 불가 데이터는 제공 단위 그대로의 합계·평균도 원칙적 반출 불가, 영리 목적은 제공기관 협의(16번).
- 기획서 PDF는 상호평가에서 다른 참가자에게 공개되므로 비공개 정보·키를 넣으면 안 됨(16번).
- 과거 제주 데이터 공모전(2025 제주관광 데이터 활용 공모전) 대상은 "기존 지표의 빈틈을 짚고, 데이터 여러 종을 결합해, 정책 자원 투입이라는 행동으로 잇는" 구조였다. 같은 주최·운영 조합의 에이전트 대회 선례는 못 찾음(15번).
- 전문가 평가는 설치가 한 번 실패하면 기술성·재현성·편의성이 함께 무너지므로 윈도우 원클릭 설치, 외부 LLM 키가 없을 때의 대체 경로, 센터 형식 그대로의 가상 CSV 동봉이 주제보다 앞선다(15번).
- 외부 LLM 비용 추정: 질문당 Claude Haiku 약 5원, Sonnet 약 100원(14번, 사용량·환율 가정).

## 4. 2단계 공통 평가 기준 (모든 후보에 똑같이 적용)

1. 심사 배점 예상(분석 주제 타당성·창의성 15, 필수 데이터 활용 20, AI Agent 기술성·완성도 25, 편의성·실용성 25, 결과 신뢰성·재현성 15)
2. 상호평가에서 기획서 두 개를 나란히 놓았을 때 이길 가능성

4. 시연 가능성(센터 데이터 없이 가상 데이터나 공개 API로 평가 환경에서 실제로 돌아가는가)
5. 구현 가능성(개발자 1명, 실제 5일 안팎)
6. 규정 위험(16번 기준)
