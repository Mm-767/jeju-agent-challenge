# 데이터 활용 명세: 행사 효과 나란히

작성 2026-11-14(초안). 유동인구 스냅샷 행 수는 수집이 끝나는 11/15 이후 다시 적는다.

이 Agent는 데이터 세 가지를 쓴다. 센터 카드 데이터는 이용자가 센터 PC에서 넣고 그 PC 안에서만 계산한다. 제주데이터허브 공개 자료 두 가지는 개발 때 받아 스냅샷으로 동봉하고, 실행 중에는 허브를 부르지 않는다.

## 1. 카드 이용 현황(읍면동)_v02 — 제주빅데이터센터(필수 데이터)

| 항목 | 내용 |
|---|---|
| 출처 | 제주빅데이터센터 분석 PC, 데이터 명세서 1-08(v13) |
| 기간과 단위 | 2023년 8월부터 월 단위. 한 번에 한 달씩 받는다 |
| 쓰는 열 | base_year_month(연월), bjd(법정동, 읍면 12곳만), biz_cd(업종), tour_type(개별·단체만), user_cnt·use_cnt(10 미만 검사), use_amt(이용 금액) |
| 쓰지 않는 행 | 동 지역, 제주도민(tour_type 도민), 이 밖의 열은 읽기만 하고 버린다 |
| 전처리 | 행마다 연월을 판별해 (읍면, 연월, 업종)별로 관광객 이용 금액·건수·인원을 더한다. 한 파일에 여러 달이 있어도 받고, 이미 넣은 달과 겹치는 파일, 같은 행이 두 번 있는 파일, 엑셀로 다시 저장한 파일은 거절한다. 숫자가 NA나 빈칸인 칸은 10 미만으로 본다 |
| 계산 | 행사 직전 3개월 대비 행사 달의 증가율을 행사 읍면과 비교 읍면에서 구해 상대 효과를 낸다(이중차분). 행사 전 3개월 흐름 확인, 행사가 없던 달로 같은 계산을 한 값의 분포(p값)를 함께 낸다 |
| 10 미만 처리 | 계산에 쓰는 모든 달과 두 읍면에서 업종 묶음의 건수 또는 인원(업종별 인원의 최댓값)이 10 미만이면 업종 범위를 중분류, 대분류, 42개 전체 순으로 넓힌다. 그래도 남으면 비교 읍면을 바꾸거나 계산하지 않는다 |
| 이용 조건 | 원본 반출 불가. 결과물(png·PDF)에는 증가율, 상대 효과, 기준 기간 평균을 100으로 둔 지수, 개수만 넣고 원래 금액·건수·인원과 그 합계는 넣지 않는다. 외부 AI로 보내지 않는다(외부 연결은 파일을 받기 직전에 잠긴다) |
| 동봉 | 없음. 같은 형식의 가상 데이터만 동봉한다(4절) |

## 4. 가상 카드 데이터(동봉, 실제 통계 아님)

센터 데이터를 가져올 수 없으므로 같은 열·형식(모든 값 큰따옴표, NA, 한 달 한 파일)으로 만든 가상 데이터를 동봉한다. tools/make_dummy_card.py가 고정 난수로 만든다.

| 폴더 | 내용 | 파일 / 행 |
|---|---|---|
| data/dummy/card_effect | 시험 행사가 열린 달에 관광객 소비 증가를 심은 판(예시 경로) | 37개 / 132,275행 |
| data/dummy/card_none | 같은 난수로 효과를 심지 않은 판("효과를 심지 않은 가상 데이터로 해 보기") | 37개 / 132,275행 |
| data/dummy/card_rehearsal | 다른 난수로 만든 리허설용 판. AI가 세운 계획을 계산 경로에 미리 돌려 보는 데만 쓴다 | 37개 / 132,867행 |

리허설용 판을 예시용과 다른 난수로 만든 것은, 공개 단계에서 외부 AI에 돌려주는 리허설 결과가 예시 결과와 섞이지 않게 하려는 것이다.

## 5. 외부로 보내는 것

실행 중 외부 주소는 https://api.anthropic.com 하나다. 보내는 것은 행사 이름·날짜, 공개 유동인구 요약값과 조회 결과, 거리 표, 같은 시기 행사 목록, 장소 추정, 리허설 검사 결과 문장뿐이다. 센터 카드 파일을 받기 직전에 외부 연결을 잠그고, 잠긴 뒤의 AI 호출은 보내지 않고 막는다. 보낸 요청 본문은 모두 화면의 「외부 전송 기록」에서 볼 수 있다.
