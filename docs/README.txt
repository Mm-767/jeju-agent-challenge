행사 효과 나란히
제주 읍면 축제의 관광객 카드 소비를 비교 읍면과 나란히 놓고 계산하는 AI Agent

이 프로그램은 「제주 AI·빅데이터 활용 AI Agent 개발 챌린지」 제출작입니다.
결과물은 제주빅데이터센터가 비독점으로 이용할 수 있으며, 저작권은 제출자에게 있습니다.


■ 심사위원께: 3분 확인 순서

1. install.bat을 더블클릭해 설치 점검이 모두 PASS인지 봅니다(처음 한 번만, 약 1분).
2. run.bat을 더블클릭합니다. 브라우저가 열리면 「예시로 해 보기」를 누릅니다.
3. 「장소 확인」을 누르면 AI가 공개 유동인구를 조회하며 계산 계획을 세웁니다(30초~1분).
   오른쪽 작업 기록에 AI가 무엇을 왜 조회했는지가 쌓입니다.
4. 위쪽 띠의 「외부 전송 n건」을 누르면 밖으로 보낸 요청 본문을 모두 볼 수 있습니다.
   공개 자료와 계획만 있고 센터 데이터는 없습니다.
5. 「이 계획으로 센터 파일 넣기」 다음 화면에서 Wi-Fi를 끈 뒤
   「동봉한 가상 데이터로 계속(시험용)」과 「계산 시작」을 누릅니다.
   파일을 넣는 순간 외부 연결이 잠기고, 인터넷 없이 결과가 나옵니다.
6. 「끝내기」를 누르면 작업 기록과 결과가 지워지고 잠금이 풀립니다.
7. 위쪽 띠 「외부 전송 n건」 창의 「자가 점검」을 누르면, 무작위 표시값을 심은 가상 데이터로
   잠금 뒤 외부 전송 0건과 결과 글자 속 표시값 0건을 프로그램이 직접 확인합니다.


■ 설치와 실행

필요한 것: Windows 10 또는 11(64비트), Chrome 또는 Edge. Python을 따로 설치하지 않습니다(묶음에 들어 있음).

1. ZIP을 C:\EventEffect 처럼 짧은 경로에 압축 해제합니다.
   (압축을 풀지 않고 ZIP 안에서 바로 실행하면 동작하지 않습니다.)
2. install.bat: 설치 점검. 모든 항목이 PASS여야 합니다. 결과는 app\out\install_check.txt에도 남습니다.
3. run.bat: 프로그램 실행. 브라우저가 저절로 열립니다(주소 http://127.0.0.1:18501 부근).
   이 검은 창을 닫으면 프로그램이 끝납니다. 이미 실행 중이면 브라우저만 다시 엽니다.


■ 평가용 설정

- app\.env 에 평가용 Anthropic API 키가 들어 있습니다(모델 Claude Haiku 5.5).
- 센터에서 운영할 때는 담당자가 윈도우 환경변수 ANTHROPIC_API_KEY에 센터 키를 넣으면
  app\.env보다 그 값을 먼저 씁니다(설정 뒤 run.bat을 새로 실행).
- 실행 중 접속하는 외부 주소는 https://api.anthropic.com 하나뿐입니다.
- 키가 없거나, 인터넷이 막혔거나, AI 응답이 검사를 통과하지 못하면
  「미리 만든 계획」(개발 중 같은 프로그램이 실제로 만든 계획)으로 동작하고 화면에 그렇게 표시합니다.
  미리 만든 계획은 계산할 수 있는 읍면 행사 26개에 있고, 장소 확인에서 고른 읍면이 계획의 읍면과 같을 때 씁니다.


■ 같은 결과가 나오는지(재현성)

- 같은 계획 묶음과 같은 CSV를 넣으면 숫자는 늘 같습니다. 계산은 표본 추출이 없는 코드입니다.
- 받을 달과 비교 순서는 코드가 행사 날짜와 공개 유동인구로 정하므로 실행마다 같습니다.
- AI에 연결된 상태에서는 방문 판단 문장, 추가 제외, 업종 범위, 문장 틀이 실행마다 조금 다를 수 있고,
  추가 제외나 업종 범위가 달라지면 숫자도 달라집니다. 어떤 판단을 썼는지는 결과 폴더의 계획 묶음과 근거표에 남습니다.
- 키 없이 실행하면 미리 만든 계획을 쓰므로 늘 같은 결과가 나옵니다.


■ 결과 삭제

- 위쪽 띠의 「결과 자동 삭제」가 켜져 있으면(기본) 「끝내기」 때 결과 그림과 PDF까지 지웁니다.
- 꺼 두면 결과 폴더(app\out\report)의 그림·PDF를 남깁니다. 메모리의 센터 집계와 작업 기록은 언제나 지웁니다.
- 이 설정은 프로그램을 다시 켜도 유지됩니다. 켜져 있으면 다음 실행 때 지난번에 남은 결과도 지웁니다.
- 반출 승인 자료 외에는 퇴실 전에 지워야 합니다.


■ 문제가 생기면

- 「Windows의 PC 보호」 창: 「추가 정보」 → 「실행」을 누릅니다(인터넷에서 받은 파일 표시).
- 설치 점검에 FAIL이 있으면 그 화면을 찍어 두면 원인 확인에 도움이 됩니다.
- 브라우저가 열리지 않으면 검은 창에 적힌 주소를 Chrome 주소창에 붙여 넣습니다.
- 검은 창을 마우스로 누르면 서버가 멈출 수 있습니다. 멈추면 Esc 키를 누릅니다.


■ 폴더 구성

install.bat, run.bat      설치 점검과 실행
THIRD_PARTY_NOTICES.txt   동봉한 오픈소스 34개와 Python의 라이선스 고지
docs\                     사용자 매뉴얼(manual_ko.pdf), 데이터 활용 명세(data_spec_ko.pdf), 결과 설명자료(result_ko.pdf)
python\                   동봉한 Python 3.11.9와 패키지
app\                      프로그램(코드, 프롬프트, 화면, 공개 데이터 스냅샷, 가상 데이터)
app\prompts\              AI에게 주는 지시문과 도구 정의
app\data\hub\             제주데이터허브 공개 자료 스냅샷(유동인구, 행사 파일, 장소 추정표)
app\data\dummy\           센터 카드 데이터와 같은 형식의 가상 데이터(실제 통계 아님)
app\tests\                검증용 자동 시험
