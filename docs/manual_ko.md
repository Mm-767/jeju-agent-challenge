# 행사 효과 나란히 사용자 매뉴얼

제주 읍면 축제의 관광객 카드 소비를 비교 읍면과 나란히 놓고 계산하는 AI Agent

이 문서는 두 사람을 위해 썼습니다. 1~3절은 프로그램을 설치하는 센터 담당자, 4~7절은 축제 효과를 알고 싶은 이용자(축제 담당 공무원, 축제추진위원회 사무국, 관광 협회 직원)가 읽습니다. 8절은 오류와 제약, 9절은 센터 운영자가 공개 자료를 새로 받는 방법, 10절은 사용한 AI와 라이브러리입니다.

## 1. 처음 알아 둘 것

이 프로그램은 축제가 열린 읍면과 축제가 없던 비교 읍면의 관광객 카드 소비가 행사 직전 3개월보다 얼마나 달라졌는지를 나란히 놓고, 그 차이를 반출 신청할 수 있는 그림과 PDF로 만듭니다.

일은 두 단계로 나뉩니다.

| 단계 | 쓰는 자료 | 외부 연결 | 하는 일 |
|---|---|---|---|
| 계획 | 제주데이터허브 공개 자료(행사 목록, 유동인구, 동봉) | 열림 | AI가 공개 유동인구를 조회하며 방문 판단, 비교에서 뺄 읍면, 업종 범위를 정한다 |
| 계산 | 센터 카드 이용 현황(읍면동)_v02 | 잠김 | 이 PC 안에서만 계산하고 결과 문장, 그림, PDF를 만든다 |

센터 카드 파일을 넣는 순간 외부 연결이 잠기고, 잠긴 뒤에는 AI 호출을 보내지 않고 막습니다. 밖으로 보낸 요청 본문은 모두 화면 위쪽 「외부 전송 n건」에서 볼 수 있습니다.

AI가 정하는 것과 코드가 정하는 것은 이렇게 나뉩니다.

- AI가 정함: 행사 기간에 방문이 늘었는지에 대한 판단, 비교 읍면 후보 가운데 더 뺄 곳과 그 이유, 계산할 업종 범위, 결과 문장의 틀
- 코드가 정함: 받을 달, 비교 읍면의 순서, 모든 숫자 계산, 10 미만 칸 처리, 결과 문장의 숫자 채우기, 반출 사전 점검

결과는 비교 읍면 대비 차이입니다. 행사가 소비를 늘렸다는 인과 효과를 증명하지 않습니다.

## 2. 설치

### 2-1. 필요한 것

| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10 또는 11, 64비트 |
| 브라우저 | Chrome 또는 Edge |
| 디스크 | 압축을 푼 뒤 약 215MB |
| 인터넷 | 계획 단계에서 AI를 쓸 때만. 없으면 예시 행사만 「미리 만든 계획」으로 동작(8절) |
| 따로 설치할 것 | 없음. Python 3.11.9와 패키지 34개가 묶음에 들어 있다 |

### 2-2. 압축 풀기

1. ZIP을 `C:\EventEffect`처럼 짧은 경로에 압축 해제합니다. 한글이나 띄어쓰기가 있는 폴더도 됩니다.
2. 압축을 풀지 않고 ZIP 안에서 바로 실행하면 동작하지 않습니다.

### 2-3. 설치 점검(install.bat)

`install.bat`을 더블클릭합니다. 처음 한 번만 하면 되고 약 1분 걸립니다. 「Windows의 PC 보호」 창이 뜨면 「추가 정보」를 누른 뒤 「실행」을 누릅니다.

검은 창에 아래 8개 항목이 차례로 찍힙니다. 모두 PASS여야 합니다. 결과는 `app\out\install_check.txt`에도 남습니다.

| 항목 | 확인하는 것 |
|---|---|
| Python 판 3.11.9 | 동봉한 Python이 실행되는가 |
| UTF-8 모드 | 한글 파일 이름과 내용을 깨지지 않게 읽는가 |
| 모든 패키지 불러오기 | 패키지 34개가 모두 불러와지는가 |
| 윈도우 기준 빠진 의존성 없음 | 윈도우에서만 필요한 부품이 빠지지 않았는가 |
| 한글 그림(png) 그리기 | 맑은 고딕으로 한글 그림을 그릴 수 있는가 |
| 현재 폴더 경로의 카드 CSV 읽기 | 압축을 푼 경로에서 동봉한 가상 CSV를 읽는가 |
| 원격 측정 내보내기 부품 없음 | 사용 기록을 밖으로 보내는 부품이 없는가 |
| 외부 AI 호출 | 키가 있으면 AI에 짧은 호출 한 번을 보내 응답을 받는가. 키가 없으면 건너뛴다 |

FAIL이 있으면 그 창을 찍어 두면 원인을 찾는 데 도움이 됩니다(8-1절).

### 2-4. 실행(run.bat)

`run.bat`을 더블클릭하면 브라우저가 저절로 열립니다. 주소는 `http://127.0.0.1:18501`이고, 그 번호를 다른 프로그램이 쓰고 있으면 18502~18510 가운데 빈 번호를 씁니다.

- 프로그램은 이 PC 안(127.0.0.1)에만 열리고 다른 PC에서는 접속할 수 없습니다.
- 검은 창을 닫으면 프로그램이 끝납니다.
- 이미 실행 중일 때 다시 누르면 「이미 실행 중입니다. 브라우저만 엽니다.」가 뜨고 열려 있는 화면을 다시 엽니다.

## 3. AI 키 설정

계획 단계는 Anthropic의 Claude Haiku 5.5를 씁니다. 키는 두 곳에서 읽고, 위쪽이 먼저입니다.

1. 윈도우 환경변수 `ANTHROPIC_API_KEY`: 센터에서 운영할 때 담당자가 센터 키를 넣는 곳
2. `app\.env` 파일의 `ANTHROPIC_API_KEY=` 줄: 평가용 키가 들어 있는 곳

환경변수는 「시작」에서 「시스템 환경 변수 편집」을 연 뒤 「환경 변수」에서 새로 만들거나, 명령 프롬프트에서 아래처럼 넣습니다. 넣은 뒤에는 `run.bat`을 새로 실행해야 반영됩니다.

```
setx ANTHROPIC_API_KEY "센터에서 발급한 키"
```

한 번의 계획에서 AI 호출은 최대 16번으로 막혀 있습니다. 실행 중 접속하는 외부 주소는 `https://api.anthropic.com` 하나뿐이고, 제주데이터허브는 부르지 않습니다(공개 자료는 동봉한 스냅샷을 씁니다).

## 4. 화면 따라 하기

화면은 왼쪽 본문과 오른쪽 「작업 기록」으로 나뉩니다. 작업 기록에는 AI가 무엇을 왜 조회했는지, 코드가 무엇을 검사하고 계산했는지가 차례로 쌓입니다. 표시는 「AI 짐작」「조회」(AI), 「검사」「계산」「잠금」(코드), 「대체 경로」「멈춤」「오류」(주의)로 나뉩니다.

### 4-1. 예시로 해 보기(약 2분)

처음이라면 이것부터 해 봅니다. 가파도청보리축제(2024년 4월, 대정읍)를 센터 카드 데이터와 같은 형식의 가상 데이터로 끝까지 돌립니다. 위쪽 띠에 「예시(가상 데이터)」가 표시됩니다.

1. 「예시로 해 보기」를 누릅니다.
2. 「장소 확인」 화면에서 대정읍이 골라져 있는 것을 보고 「장소 확인」을 누릅니다.
3. AI가 계획을 세우는 동안 30초~1분 기다립니다. 계획이 나오면 「이 계획으로 센터 파일 넣기」를 누릅니다.
4. 「동봉한 가상 데이터로 계속(시험용)」을 누르고 「계산 시작」을 누릅니다.
5. 결과를 본 뒤 「끝내기」를 누릅니다.

첫 화면의 「효과를 심지 않은 가상 데이터로 해 보기」는 효과를 넣지 않은 가상 데이터로 같은 과정을 돌립니다. 이때는 「차이가 없다」에 가까운 결과가 나와야 정상입니다.

### 4-2. 직접 분석하기

**① 행사 고르기.** 「직접 분석하기」를 누르면 제주특별자치도 주요행사정보 가운데 동봉한 공개 유동인구 기간(2023년 8월~2026년 8월)에 시작한 213건이 표로 나옵니다. 「볼 수 있는 행사만」이 켜져 있으면 날짜로 계산할 수 있는 52건 가운데 동 지역 행사를 뺀 33건만 보입니다. 「볼 수 있나」 칸의 뜻은 이렇습니다. 걸침 비중은 그 달 일수 가운데 행사가 열린 날의 비중입니다.

| 표시 | 뜻 |
|---|---|
| 볼 수 있음 | 행사가 어느 한 달의 절반 이상에 걸친다 |
| 희석 주의 | 가장 많이 걸친 달도 4분의 1~절반이라, 계산은 되지만 한 달 합계에 효과가 묽어질 수 있다 |
| 볼 수 없음: 날짜 오류 | 행사 파일의 끝 날짜가 시작보다 앞선다 |
| 볼 수 없음: 92일 넘는 장기 행사 | 행사 직전 3개월과 비교할 수 없다 |
| 볼 수 없음: 한 달 합계에 묻히는 짧은 행사 | 어느 달에도 4분의 1 이상 걸치지 않는다 |
| 볼 수 없음: 행사 전 카드 자료 부족 | 카드 자료가 시작되는 2023년 8월 이전 달이 필요하다 |
| 볼 수 없음: ○○동(읍면만 지원) | 동 지역 행사. 카드 자료에서 읍면 12곳만 다룬다 |

**② 장소 확인.** 행사 파일에는 장소 열이 없어서 AI가 행사 이름과 주관·주최로 개최 읍면을 짐작해 둔 값이 「AI 짐작」으로 보입니다. 틀릴 수 있으므로 실제 개최 읍면을 골라 「장소 확인」을 누릅니다.

**③ AI 계산 계획.** AI가 공개 유동인구를 조회하며 계획을 세웁니다(30초~1분). 화면에는 이것이 나옵니다.

- 계획의 출처: 「AI가 방금 세운 계획」 또는 「미리 만든 계획」
- 방문 판단: 행사 기간 일평균 방문 인구를 직전 4주 같은 요일 평균과 비교한 결과와 AI의 판단
- 비교 순서: 행사 전 12개월 동안 유동인구 흐름이 행사 읍면과 가장 나란했던 읍면부터. 순서는 코드가 정한다
- 뺀 읍면: 같은 시기에 다른 축제가 있어 규칙으로 뺀 곳과 AI가 이유를 들어 더 뺀 곳
- 업종 묶음: 코드가 정해 둔 묶음 4개(관광 소비 전체, 먹거리·음료 중심, 숙박·체류 중심, 42개 전체) 가운데 AI가 고른 것과 그 이유

AI가 세운 계획은 다른 난수로 만든 리허설용 가상 데이터로 계산 경로를 미리 돌려 본 뒤에만 화면에 나옵니다. 계획을 세우지 못하면 「계산 계획을 세우지 못했습니다」가 나옵니다. 작업 기록에서 이유를 보고 「끝내기」 뒤 다른 행사를 고릅니다.

**④ 센터 카드 파일 넣기.** 화면 맨 위에 필요한 달이 「필수 n개, 평소 흔들림 계산용 n개, 모두 n개월」로 나옵니다. 센터에서는 한 번에 한 달씩 받으므로, 필요한 달을 운영자에게 한 번에 요청해 받은 「카드 이용 현황(읍면동)_v02」 CSV를 모두 끌어다 놓거나 「파일 선택」으로 고릅니다. 한 파일에 여러 달이 들어 있어도 됩니다.

첫 파일이 들어오는 순간 외부 연결이 잠기고 위쪽 띠가 「외부 AI 연결 잠김」으로 바뀝니다. 파일은 디스크에 저장하지 않고 메모리에서 바로 집계합니다. 받을 수 없는 파일은 이유와 함께 거절합니다.

| 거절 문구 | 할 일 |
|---|---|
| 엑셀에서 저장한 파일로 보입니다 | 엑셀로 열어 다시 저장하면 형식이 바뀐다. 센터에서 받은 원래 파일을 넣는다 |
| 이 파일은 카드 이용 현황(읍면동)_v02 형식이 아닙니다 | 다른 데이터의 파일이다 |
| 같은 행이 두 번 들어 있습니다 | 파일을 합치다 행이 겹쳤다. 원래 파일을 넣는다 |
| ○○년 ○월 자료가 이미 넣은 파일에도 있습니다 | 같은 달을 두 번 넣었다. 하나만 남긴다 |
| 자료가 들어 있지 않은 파일입니다 | 빈 파일이다 |

필요한 달이 다 들어오면 「계산 시작」이 눌립니다.

**⑤ 결과.** 결과 화면에는 이것이 나옵니다.

결과는 화면과 PDF 모두 결론부터 읽는 보고서 순서(결론, 상황, 과제, 방법, 결과, 한계와 활용)로 나옵니다.

| 칸 | 들어 있는 것 |
|---|---|
| 1. 결론 | 판정(평소엔 드문 차이, 평소에도 생기는 차이, 계산하지 못함), 결론 한 줄, 결과 문장, 핵심 숫자(상대 효과, p값, 행사가 없던 달 가운데 이번보다 큰 차이) |
| 2. 상황 | 행사, 기간, 개최 읍면, 공개 방문 인구 판단 |
| 3. 과제 | 물음, 비교 읍면, 기준 기간, 행사 달, 업종 묶음 |
| 4. 방법 | 쉬운 말 설명, 계산 세 단계(증가율 비교, 행사 전 흐름 확인, 평소 차이 확인)와 각 단계의 숫자, AI가 정한 것과 이유 |
| 5. 결과 | 계산 근거표, 달별 지수 그림(기준 기간 평균 100), 공개 방문 인구 그림 |
| 6. 한계와 활용 | 이 행사에서 주의할 점, 모든 결과에 공통인 한계(접어 둠), 반출 신청: 「보고서 PDF 열기」, 「활용 사유 문안」과 「활용 사유 복사」 |

결과물에는 증가율, 상대 효과, 지수, 개수만 들어 있고 원래 금액·건수·인원과 그 합계는 들어 있지 않습니다. 화면의 「반출 신청 가능(사전 점검 기준)」은 프로그램이 결과물을 검사한 결과이고, 실제 반출 승인은 센터가 합니다.

## 5. 외부 전송 기록과 자가 점검

위쪽 띠의 「외부 전송 n건」을 누르면 이 프로그램이 밖으로 보낸 요청이 시각과 목적별로 나옵니다. 「보낸 본문 펼치기」로 보낸 글자를 그대로 볼 수 있습니다. 보내는 것은 행사 이름과 날짜, 공개 유동인구 요약과 조회 결과, 비교 읍면 거리 표, 같은 시기 행사 목록, 장소 짐작, 리허설 검사 결과 문장뿐입니다.

같은 창의 「자가 점검」을 누르면 무작위 9자리 표시값을 심은 가상 카드 데이터로 계산 단계를 한 번 돌리고, 아래 7가지를 프로그램이 직접 확인해 보여 줍니다.

1. 잠금 뒤 외부로 나간 요청이 0건인가
2. 잠금 뒤 일부러 한 AI 호출이 막혔는가
3. 전송 기록에 표시값과 그 칸의 합계가 없는가
4. 결과 글자에 표시값과 그 칸의 합계가 없는가
5. 결과 폴더에 그림·PDF·계획 묶음 말고 다른 파일이 없는가
6. 사용 기록을 밖으로 보내는 부품이 없는가
7. 점검이 끝난 뒤 잠금이 풀렸는가

자가 점검은 끝날 때 잠금을 풀기 때문에, 센터 파일을 넣은 뒤에는 누를 수 없습니다. 「끝내기」 뒤에 누릅니다.

## 6. 끝내기와 결과 삭제

「끝내기」를 누르면 확인 창이 뜨고, 「지우고 끝내기」를 누르면 아래를 지운 뒤 처음 화면으로 돌아가고 외부 연결 잠금을 풉니다.

| 지우는 것 | 결과 자동 삭제 켜짐(기본) | 꺼짐 |
|---|---|---|
| 메모리의 센터 카드 집계 | 지움 | 지움 |
| 작업 기록과 외부 전송 기록 | 지움 | 지움 |
| 결과 폴더 `app\out\report`의 그림·PDF·계획 묶음 | 지움 | 남김 |

위쪽 띠의 「결과 자동 삭제 켜짐」을 누르면 꺼짐으로 바뀝니다. 반출 신청할 결과를 남겨 두어야 할 때만 끄고, 반출 승인 자료 외에는 퇴실 전에 지워야 합니다.

이 프로그램은 센터 카드 원본과 집계를 디스크에 저장하지 않습니다. 결과 폴더에 남는 것은 반출 신청용 그림·PDF와 계획 묶음뿐이므로 따로 보존할 집계값은 없습니다.

## 7. 결과 읽는 법

| 결과 | 뜻 |
|---|---|
| 더 늘었다 | 행사 읍면이 비교 읍면보다 더 늘었고, p값이 0.1 이하다 |
| 덜 늘었다 | 행사 읍면이 비교 읍면보다 덜 늘었고, p값이 0.1 이하다 |
| 평소에도 생기는 크기의 차이 | p값이 0.1보다 크다 |
| 계산하지 못했다 | 아래 이유 가운데 하나 |

p값은 행사가 없던 달을 가짜 행사 달로 두고 같은 계산을 했을 때, 이번 차이보다 크거나 같은 차이가 나온 비율입니다. 행사가 없던 달이 9개보다 적으면 계산하지 않습니다.

계산하지 못하는 이유는 다섯 가지입니다. 행사 전 흐름이 나란한 비교 읍면을 찾지 못함, 작은 칸을 업종 전체로 묶어도 10 미만이 남음, 비교할 수 있는 읍면이 부족함, 행사가 없던 달이 부족해 평소 흔들림을 계산할 수 없음, 필요한 달의 카드 파일이나 행사 읍면 자료가 없음.

계산 방법은 결과 화면과 PDF의 「4. 방법」에, 자세한 설명은 결과 설명자료(docs/result_ko.pdf)에 있습니다.

## 8. 오류와 제약

### 8-1. 문제가 생기면

| 증상 | 할 일 |
|---|---|
| 「Windows의 PC 보호」 창 | 「추가 정보」를 누른 뒤 「실행」을 누른다 |
| 설치 점검에 FAIL | 창을 찍어 둔다. `app\out\install_check.txt`에도 같은 내용이 있다 |
| 외부 AI 호출만 FAIL | 인터넷이나 키 문제다. 나머지 기능은 동작하고 예시 행사는 「미리 만든 계획」으로 돌아간다 |
| 브라우저가 열리지 않음 | 검은 창에 적힌 주소를 Chrome 주소창에 붙여 넣는다 |
| 「포트 18501~18510을 모두 다른 프로그램이 쓰고 있습니다」 | 다른 프로그램을 닫거나 PC를 다시 시작한다 |
| 화면이 멈춘 것 같음 | 계획 단계는 1분까지 걸린다. 오른쪽 작업 기록이 늘고 있으면 기다린다 |
| 작업 기록에 「안내: 앞의 작업이 끝나지 않았습니다」 | 계획이나 계산이 진행 중이다. 끝날 때까지 기다린다 |
| 작업 기록에 「안내: 센터 파일을 넣은 뒤에는 AI 단계로 돌아갈 수 없습니다」 | 잠긴 뒤에는 계획을 다시 세울 수 없다. 「끝내기」 뒤 다시 시작한다 |

### 8-2. 제약

- AI에 연결하지 못하면(키 없음, 인터넷 막힘, AI 응답이 검사를 통과하지 못함) 「미리 만든 계획」으로 동작하는데, 미리 만든 계획은 예시 행사(가파도청보리축제)에만 있습니다. 다른 행사는 AI 연결이 있어야 계획을 세울 수 있습니다.
- 읍면 12곳만 다룹니다. 제주시·서귀포시 동 지역 행사는 계산하지 않습니다.
- 동봉한 공개 유동인구는 2023년 8월 1일~2026년 8월 31일입니다. 그 뒤 행사는 9절대로 새 달을 받아야 비교 읍면 순서를 정할 수 있습니다.
- 행사 목록은 제주특별자치도 주요행사정보 파일에 있는 행사만 봅니다. 같은 시기 다른 축제로 비교 읍면을 빼는 판단도 이 파일만 봅니다.
- 장소는 AI 짐작이라 이용자가 확인해야 합니다.
- 센터 보안 프로그램이 브라우저 파일 올리기를 막는 경우는 확인하지 못했습니다.

## 9. 센터 운영자용: 공개 자료 새로 받기

아래 도구는 평가와 일상 사용에는 필요 없습니다. 공개 자료를 새 달로 넓힐 때만 씁니다. 명령은 압축을 푼 폴더에서 명령 프롬프트로 실행합니다.

**공개 유동인구.** 제주데이터허브에서 프로젝트 키를 받아 `app\.env`에 `HUB_PROJECT_KEY=키` 줄로 넣고 실행합니다. 읍면별 파일의 마지막 날짜 다음부터 이어 받습니다. 읍면 하나의 한 달은 약 5번 호출이고, 허브 API는 하루 호출 한도가 있어 한도에 걸리면 다음 날 다시 실행합니다.

```
python\python.exe -X utf8 app\tools\fetch_population.py --end 2026-10-31
```

**행사 목록.** 허브에서 「제주특별자치도 주요행사정보」 CSV를 내려받아 실행하면 `app\data\hub\events.csv`를 새로 만듭니다. 장소 짐작이 없는 행사는 「모름」으로 보이고, 장소 확인 화면에서 고르면 됩니다. 행사 번호가 원본 행 번호라, 원본의 행 순서가 바뀌면 장소 짐작이 다른 행사에 붙을 수 있습니다.

```
python\python.exe -X utf8 app\tools\import_events.py 내려받은파일.csv
```

**자동 시험.** 계산, 파일 검사, 결과물 점검을 포함한 자동 시험 65개를 돌립니다.

```
python\python.exe -X utf8 -m unittest discover -s app\tests
```
